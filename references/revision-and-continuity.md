# 声音与可靠性分开检查

以下吸收《守灯人》实际修复过程，解决事实和编辑问题，不将该项目的冷暖、价值判断或剧情移植成作者的通用文风。作者允许风格规则大改，不表示允许复制合并错误。

## 工作方式

短篇或单场景，只核受影响的前后文。长篇在动笔前读当前源稿、章节来源、项目备注及已批准改动，维护简要记录：

- 时间与空间：何日/何夜、旅途耗时、年龄、角色在哪、怎样抵达。
- 物件与能力：谁持有、怎样交付、损坏或消耗是否不可逆；术法范围、成本、感知与通信媒介能做什么。
- 人物知识：谁亲见，谁转述，谁猜测，证据支持到哪一步。允许叙述者知道更多，但角色不能无故共享消息。
- 关系与线索：未兑现承诺、损失、猜疑，最后一次出现位置，计划解答或主动开放。

不必每章打印表格，不凭摘录索引宣称完成逐句审校。已确认事实、人物说法和作者尚未决定之处分别记录。

## 本项目暴露的典型错误及可迁移修法

| 实际错误 | 可迁移原则 | 修订动作 |
| --- | --- | --- |
| 扶灯、敲手背、推碗等重复动作或整段合并残留 | 真正的重复与有意回环分开 | 检查上下文是否同一事件，去掉多余版本，并核衔接主语 |
| 紧急救援中插长段学徒生活、审判前插另一条寻人戏 | 先承接上一场尚未兑现的压力 | 移至恢复或重建时段，修前后指代和时间，不只剪贴 |
| 死兽已经埋好，随后回去尸旁、再埋一次 | 动作具有不可逆状态 | 合并为一次处理，把后段改成立标记等确实尚未完成的事 |
| 父亲尚困闸内却已当面清物修窗 | 生活状态不能提前解锁 | 将整段移到获救后的接治站，同时核其他人物是否到场 |
| 布狗未赠已装包；灯架交给别人后又在本人物袋里 | 物件有履历 | 用赠送、归还、残件、预备包布等真实过渡，不能悄悄复制 |
| 声匣里看到远端签字、纸件，或断言对方没有报出的动作 | 通信有模态边界 | 改口述、报工号、可听见的动静或实际运输；若要图像功能须先建立世界事实 |
| 增益或术式已卸下，战末仍按原效果回血；借存器件未取回便重新装用 | 能力效果跟随当前载入和保管状态 | 对照这一场实际装备与前置练习，补真实领换；失去的效果另用站位、支撑或既有能力解决，不临时添新功效 |
| 两具机关只制住一具便全场安全；人在南阶却先摸到中央钥位 | 场面中的数量和位置须有承接 | 数清仍能行动的威胁与实际到达的执行位，补相应的牵制、停机或移位；不把待位、已插入、已执行写成同一状态 |
| 夜深后又“天黑前”；十年后却无条件称成人 | 相对时间要有参照 | 建时间链，明确次日或核准年龄设定；玄幻成长特例也需交代 |
| 三年前亲手交接者又被说成死去八年 | 回忆与档案同用一条时间轴 | 核原始事件、消息真假、叙述可靠性；不以模糊抒情掩盖矛盾 |
| 同一耳伤在开头写成翻墙刮伤，后文又写成狗咬；角色提起从未发生的旧桥行动 | 旧伤与既往事件有唯一事实基础 | 补写回忆先核已写场景，决定保留哪一种后，同步所有回指，不给角色添加未经叙述的共同经历 |
| 审判把数周前母页的“昨日”读成开庭前一日；一次副抄交出后原件又无故回袋 | 文书时间与副本均须分清 | 将昨日锚定制页日，跨夜叙述核当时日历；分别记录原件、副抄、拓记的持有人与实际交接 |
| 没找到领用记录就认定从未领用 | 缺证与证伪有区别 | 限定角色结论，给调查下一步，允许角色误判但别偷作事实 |

优先最小有效修改；若必须重排/重写，记录迁移起止、理由与前后依赖。扩写要承担行动、关系、世界体验或后果，不用重复饭局、清单、训话来补数字。

局部扩写后连读新段与两侧原句，核是否把同一次拆甲、带路、收牌或摊纸又写了一遍。整段复读还须重算当夜、次日和相对日数，不能只保住一句旧期限，实际行程却已多出一天。

另一条人物线在插入段中跨日，回到主线须认清回到哪一夜、哪一场，借车、借具和供药的期限仍按各自真实日时计算。不能让一段父亲独立经历，暗中给儿子的行程多添一天。

## 给《窥生》式新稿保留的自由

完整问答、叙述者评论、热闹对白和成段设定均可保留。检查的是“这一次解释是否解决当前问题”“这段评论是否重复三次”“说话人是不是同一种嘴”。不把短句、沉默、留白、间接写情绪变成新的模板。角色因激动说错话、问了不合媒介的问题，若原场已由本人、对方或叙述明确纠正，可以保留这种窘态和反应。不要把人的误言当成世界设定，也不要为了规则整齐，将所有说话人都改成先核条款、再给无误答案。

原样本有些疑点须给未来作者留选择：十年后称成人需核年龄；元境停留差异可能有成长与方法变量，主人公怀疑不等于真相；“二级/二等”是否同义需建立用语表。不能在不续写《窥生》的任务中擅改原作，也不能将这些疑点说成已解决。

## 交付

按项目的正文口径核字数，检查重复长段、人物/物件/时间的高影响接缝，所有格式从当前源稿重建。需要时核MD/TXT/HTML和章节跳转。将自动结果、编辑判断、作者待决事项分别说清楚。原稿保留，实质改写可追溯。

相似文风不等于原作者亲笔，也不等于检测通过。不生成检测分数，不改统计特征伪装来源。用户只要正文时，不把这些制作说明插入故事。

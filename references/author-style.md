# 作者文风画像与取舍

依据：完整阅读旧稿《摩炎之劫》《灵树神念》《初显身手》《浮窗媚影》《修行首日》，新稿《双元命痕》《紫殿星元》《境书之道》，并区分简介、空章和片段。下述“稳定”表示两版均有可定位现象，不表示凭8篇就能断言作者所有作品都如此。证据编号对应 evidence.md。

纯正文语料合计17,078汉字：旧稿10,290，新稿6,788。新稿的章5仅“柳府上，”3个汉字，章6为空；它们只登记，不作为成熟文风样本。新旧简介及书籍索引中的同源文案不重复计入。不能把这两份目录误称为两部完整长篇。

描述统计：旧稿引号内汉字约44.56%，新稿约65.59%；按空行划分的段落汉字中位数分别29、30。旧稿还包含只有标点的段落。比例不含引号外引语，也不是对白功能分类。相近段长、高对白比例在作者本人样本中存在，不能据此判定AI或为了匹配而追逐数值。完整方法与逐文件结果见 corpus-profile.json。

## 1. 总体声音：通俗讲述中的仙侠庄重与生活诙谐

这不是以省略、冷静和隐喻为首要手段的语言。作者倾向于把场面、人物脾气、修炼规则和情绪都告诉读者，让读者容易跟上，再用人物关系制造趣味。语言底色是现代通俗白话，宗门礼数、功法名词和短句式天道之问形成玄幻感，街市与家庭的口语又把人物拉回生活。

可用一句指导内部选择：**有话明说，有事接着发生，人物有本领也有滑稽处，热闹过后可能藏着另一回事。**不要把这句话写成小说主题。

稳定特征：在场的讲述者、明示性格与情绪、对白推动、身份称谓、动作反应链、解释型设定、能力具象化、轻松与危险相接。较偏新稿：少年与亲长斗嘴、装乖脱罚、公开谋划接私下心结、基于规则反差起疑。较偏旧稿：宗门群像、路途和地理说明、买菜烹饪等连续劳作、照顾妹妹的直接温情。宏大哲理主要出现在开篇宗祖段和简介，不能据此把全部日常改成玄言。

## 2. 句法：顺叙、承接和双动作

### 常用骨架与真实用途

| 骨架 | 样本中的用途 | 创作时怎样沿用 |
| --- | --- | --- |
| 时间/地点先行，再人物动作 | “白灵树下”“文塾堂上”“第二天清晨”；E1、E5、E7 | 新场景先给落脚点，不需要每段重复环境 |
| 见状/闻言/听罢 → 神情或动作 | E2、E5、E6、E7均可见 | 让反应贴着刚发生的刺激，保留叙述流畅感 |
| 一边A，一边B | 买菜归来帮拿箩筐；父亲训儿时的身体窘态；E3、E6 | 两个动作体现人物矛盾、忙碌或关系，不只堆动作 |
| 随着A，B越发/逐渐，最后C | 宗祖化气成印，E1 | 过程性奇观需写清变化、去向与结果 |
| 只见/随后/随即/顿时/说罢 | 叙述动作衔接和突变 | 可自然出现，重复邻近时复读，不设禁词表 |
| 问句、感叹、结巴和语气尾巴 | “诶”“呀”“啦”“这，这”；E5、E6 | 体现当下身份与情绪，避免每人同一串口头禅 |
| 庄重对举或四字短语 | 宗祖问天、简介；E1 | 用于仪式、长辈命题和宏观危机，不给买菜对话套文言 |

句子常由时间、反应、原因、动作串联，一句话允许两个至数个分句。不要为了所谓简洁全部切为短碎句。原作也有独句对白和较长说明段；段落随人物说话和行动转换，不追求长短随机分布。

语言清理只修必要处：地/得/的混用、“来着不善”一类误字、成分重复、主语漂移与不当搭配。保留口语里真实的回环；不要为了正式而将“臭小子”改为“顽劣少年”。原稿中的连续点号、破折号混排和缩进不稳定是排版问题，不是声音核心，可按项目习惯统一。

## 3. 叙述者与视角

作者会主动说某人直性子、善分析、抱着怎样的小心思，甚至调侃“小马仔”“一番丑态”。这是一种愿意领着读者看人物的讲述，不必将所有评价改成间接呈现。人物的身体反应和叙述说明可共存：先动作再一句点明，足够清楚就不再三解释同一情绪。

旧稿在群像中调度多人的感受，新稿从柳家切到万任的公开谋划和私人密室，明显容许叙述范围变化。因此本技能允许全知或游移焦点。读者要知道镜头已到何处、谁在想；不能借全知把“作者知道”变成“角色已经知道”。若当前项目约定限知，则服从该项目；人物未见的情况用另场展示或有来路的信息交代。

内心可直接写“心想”“暗自窃喜”“莫非”，不必永远借物象代替。内心与礼貌对白的反差尤其重要：口头认错不代表真的服气，礼貌请教不代表毫无警惕。

## 4. 词汇、音色与人物差异

日常白话与半文言并置，身份词比罕见形容词更能定音。少年可自称“小爷”，对父亲说“老爹”，对先生立即变“晚辈/学生”；强硬前辈对晚辈呵斥，对同辈与长者却能客气。不要把同一角色固定成只会一种腔调。

| 角色处境 | 可迁移的说话习惯 | 避免 |
| --- | --- | --- |
| 顽皮但聪明的少年 | 得意、讨价还价、先认错再找空子；对尊长有礼 | 一味傻白甜；只会讲现代网络梗 |
| 有威严的亲长 | 担忧藏在训话里；被戳中事实会支吾；也会反思 | 永远正确的说教机器 |
| 有手艺的粗直前辈 | 有明确口头习惯，谈专业会具体，看似凶却肯帮忙 | 只堆“俺”而不让本事和关照落地 |
| 年长先生 | 自称老朽，夸赞、引导、举例，偶尔忘话题 | 每句仿古；为制造“不工整”强行健忘 |
| 谋划者与合作方 | 先利益再筹码，称呼客气也可互相试探；独处时露另一动机 | 将反派写成主题辩论主持人 |

情绪可直接命名，“惊恐”“激动”“气愤”“不可置信”都是样本已有手段。关键是差异和原因，不是能否出现抽象情绪词。“脸上露出……”与“顿时……”在连续段落重复时可换成更准确动作，但不要为了修辞品位清除整个直说习惯。

## 5. 场景推进：一件小事里有数次变化

旧稿买菜场并非几句热闹对白：领人下山→鉴别食材→负重疲累→前辈帮拿→御念烹饪→少年被留下→单独照料兄妹。这条链使手艺、口碑、脾气、关照和人物关系同时成立。可迁移的是事情逐步带出人物，不是每部作品都添一场吃饭。

新稿逃宗场先让少年得意，撞墙后再挣缚，以为又能逃，最后被更强法术捆回；训斥中父亲的窘态与儿子的反驳消解威严，末尾又被少年绕走处罚。数次反转有同一个目标贯穿，适合复用其“每次努力改变眼下局面”的原则，不要每场照抄三翻四抖。

生活戏要占用合适的叙述时间。日常能展示手艺、让关系变化时可以写足，不必所有场景都只服务一根主线。若上一场正悬在救命抉择上，先兑现其直接后果，再转松弛段。不能为了执行旧规则把作者擅长的热闹生活一概判为注水，也不能靠它给字数填空。

## 6. 设定说明与奇观

作者喜欢讲清体系：层级、来源、品质、收益、限制。师长愿意教，少年也会追问。E7中问题接着问题，本来就是课堂，不应删到每问都答非所问。把课堂、训话、行家验物当作真正的场景：参与者有自尊、惊讶、盘算和无知，说明才不会变成独立说明书。

视觉化是重要桥梁：元境不是只报数值，而有禾田、竹筏、鸟、鱼，灵气有颜色、运动和形变。新奇事物先给可见形态/作用，再在需要时命名或解释。可以集中讲一组规则；超出当前问题的枝节可后移，不强制“一次只说一个术语”。

解释过的规则要能参与后续选择。父亲被震出元境、先生却能久留，是作者让知识变成疑问的代表。**但这只是角色怀疑**：孩子长大、命痕圆满与否、入境方式也可能是变量，后文应查证，不把一个反差直接认定为隐瞒修为的铁证。保留角色猜错的空间。

## 7. 章节组织与悬念

常见四字章名《摩炎之劫》《灵树神念》《双元命痕》《境书之道》，多用本章事件或核心概念命名，但《修行首日》也更直白。可作为新玄幻项目的偏好，不覆盖其他项目既有标题体系。

开场常直接落地点、时间或一句冲突。章末既可能来人/异响，也可能热闹群像、离场动作或尚未查清的推测。E4的哭笑并存和E8的带疑离场都有效；不能规定每场结尾必须留白，或每章都补一句人生金句。

时间跳跃允许干脆交代“三年后”“十年后”，无需补写所有成长过程；跳跃前后的年龄、修为和物件仍须对得上。原稿“出生十年后”接“长大成人”是应核对的年龄表达，不能将其收入生成风格。

## 8. 两版关系与生成优先级

旧稿《灵树神念》的宗祖回忆，在新稿《双元命痕》改成开篇现场，并修改了天道问答的措辞；这表示作者会重排叙事入口、修订命题，而不只是润色。新稿后续改用柳禾风、柳云宗、星元命痕体系，不是旧稿彦长离线的直接下集。不可合并人物设定，亦不能据文件系统排序推断章节顺序。

默认用共性构成声音，新稿作最近样本倾向；旧稿补充新稿尚未覆盖的群像、手艺与照料。这个默认是工作选择，作者指定任何一版或给出新样本即可调整。现有材料不足以定型作者的大战、长篇中段、恋爱发展、结局和所有题材。遇到这些需求，沿用可靠语言特征并依当次情节需要组织，不捏造“作者向来如此”。

## 9. 从旧技能保留和改写什么

| 旧倾向 | 新技能取舍 |
| --- | --- |
| 尽量展示，少解释 | 改为允许直说与解释，避免对同一信息重复证明 |
| 一场景一个近距离焦点 | 改为先定视角约定，允许作者式讲述与清楚的镜头切换 |
| 对话多打断、不完整才自然 | 撤销为通则；课堂可完整，家人可反问，是否打断服从目的 |
| 少形容、少感叹、少总结 | 改为保留作者热情与直白，只压无效复述和全员同腔 |
| 支线必须服务主线 | 放宽为可承担人物、手艺、世界生活与必要休息；紧张节点仍不能乱插 |
| 四术、救父、北路线索等 | 只放《守灯人》项目参考，不能成为通用小说设定 |
| 时间、物件、因果、导出一致性 | 保留，且与声音检查分开进行 |

最终目标是“更像作者且更可靠”，不是把作者修成一种统一的编辑腔，也不是照抄样本里的病句。
